About

Fish Is Awesome is a lightweight local inventory manager designed to help you track fish stock, prices, expiration dates, and images without relying on external services or large corporate platforms. All data is stored locally using SQLite, and all images remain on your machine.

This project was built as a small, self‑contained PHP application using:

  • PHP for backend logic and CRUD operations
  • SQLite for local data storage
  • HTML/CSS for the interface
